# XD News — apresentação para portfólio

**Criado por David Xavier, pela XD Plans.**

## Título para a seção Projetos do LinkedIn

XD News — leitor de notícias com tradução para português

## Descrição

Desenvolvi o XD News, pela XD Plans, para explorar a integração de notícias internacionais com uma experiência de leitura em português brasileiro. A aplicação usa a API Top Stories do New York Times e oferece tradução sob demanda de títulos e resumos pelo DeepL.

Construído com Next.js, React, TypeScript e Tailwind CSS, o projeto inclui favoritos locais, tema escuro, busca por categoria e interface responsiva. No servidor, implementei validação de entradas, proteção de credenciais, cache com expiração, controle de uso e tratamento de falhas externas. Os fluxos críticos são cobertos por 19 testes automatizados.

O modo demonstrativo permite explorar a interface sem credenciais, com conteúdo fictício claramente identificado. O projeto é independente, sem vínculo oficial com o New York Times; as matérias completas permanecem na fonte original.

## Competências relacionadas

Next.js · React · TypeScript · Tailwind CSS · APIs REST · Desenvolvimento full-stack · Testes automatizados · Acessibilidade web
